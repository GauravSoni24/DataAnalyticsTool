# Data Analytics Tool

> Provide a Create, Read, Update and Delete and Analytics.

---

## 📌 Overview

This project implements a real-time object detection system using YOLO to
detect and track vehicles for intelligent traffic management.
My sister runs a small business where all sales and inventory records were maintained manually in a notebook. This manual process was time-consuming, error-prone, and made it difficult to analyze business performance.

While observing this workflow, I identified an opportunity to build a software solution to simplify her data management. She wanted a system that could store, manage, and analyze sales data more efficiently.

To address this problem, I developed a desktop-based application using Pandas for structured data handling and processing, Matplotlib for generating analytical visualizations, and a GUI framework to provide an easy-to-use interface. The application helps manage records digitally and provides clear insights through data analytics.

----------

## 🚀 Features offerings:
- CRUD operation and Analytics
- Adding records in bulk with pre defined columns
- Filtering data based on multiple conditions and time series analysis
- Update and Delete as per the filter selected.
- Analytics based on existing data with beautiful graphs and structured tables.
- Change theme option to change color scheme of app.

---
